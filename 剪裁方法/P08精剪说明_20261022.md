# 第八课（购物）精剪说明（2026-10-22）

## 范围

- 原片：`raw/手语配套视频 《中国手语教程》（初级）倪兰/.../P8-8.第八课 购物_《中国手语教程》_倪兰.mp4`（1920×1080，24 fps，374.75 s）
- 候选：`中国手语教程_10课_逐词句剪裁策略_20261021.csv` 课次 8，共 85 条（词语 31、句型 6、双人对话两轮 17、单人示范两轮 17、词汇拓展-颜色 14）
- 产出：`material_candidates_P08-P10_20261022/<词句标签>/NL08_xxx_C1_<标签>.mp4`，85 条全画幅片段

## 输出规格（策略表「建议输出规格」）

1920×1080 全画幅（不按固定矩形裁剪）、24 fps、H.264/yuv420p、无音轨。
字幕与词卡内容不参与验收（同 README 第 4 条）。

## 边界确定流程（检测 + 逐条人工目检）

1. `detect_boundaries_20261022.py`：候选检索窗 ±1 s 内按 12 fps 抽灰度小图，
   计算帧间运动能量；高活性核心段向两端吸收保持帧，遇到持续 0.5 s 静息截断；
   转场淡变/硬切（整帧变化像素占比 > 0.15）作硬边界；按画面证据时刻匹配示范段。
2. 每条生成起点/终点邻域核验图（各 5 帧，`_inspect_frames/P08/strips/`）逐条目检；
   双人对话轮次另以逐秒总览图（读字幕 + 看谁在做手势）按回合重排。
3. 审定结果落盘 `中国手语教程_P08_已审定动作边界_20261022.csv`
   （起始秒 / 结束秒_不含 / 复核状态 / 核对说明）。
4. `cut_reviewed_20261022.py`：按审定表精剪并逐条机检
   （分辨率、帧率、无音轨、时长偏差 <0.3 s、完整解码），
   清单 `material_candidates_P08-P10_20261022/manifest_P08_reviewed_20261022.csv`。
