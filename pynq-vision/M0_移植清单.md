移植中发现并修复的问题（详见 AGENTS.md §4 踩坑表）：
1. Git Bash 直调 vivado 会缺 UCRT DLL 假死成僵尸进程，僵尸又锁安装目录导致
   后续构建 BD 打开报 `bd.tcl: No error`——一律走 `cmd //c run_*.bat`；
2. xpr 内 KWS HLS IP 仓库、master 约束、9 个 .v 源文件原指向旧工作区，
   已用 `fixup_paths.tcl` + xpr 文本替换全部重定位到本仓库；
3. `merge_stream.v` 必须用 492beb4 版（BD module_ref 需要 CLK_FREQ_HZ 参数，
   main 新版已删，W6 当年靠 OOC 缓存掩盖）；rtl/ 全部为冻结遗留版，见
   `fpga/rtl/README.md`；
4. 已发布固件的 BD 实际包含传感器 SPI+DMA 与旧 HLS KWS（合一工程），
   新系统闲置不用，M0b 剥离。
