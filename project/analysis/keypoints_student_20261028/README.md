## 结论（三条硬证据）

1. **训练模型打不过零学习基线**：B/C/D 全部 ≤ 基线 5.31%（NME 更差）。
   网络在留出集上学到的就是"平均手形"，之后纯记忆（best_epoch=1-2，
   与 overfit6 诊断互相印证）。
2. **增强不是瓶颈**：jitter on/off 差异（4.4% vs 5.3%）在种子方差
   （同配置 8.9% vs 4.4%）噪声之内。继续调增强没有意义。
3. **单种子结论不可信**：种子方差大于一切消融差异，任何训练策略改动
   必须多种子（≥3）验证。
