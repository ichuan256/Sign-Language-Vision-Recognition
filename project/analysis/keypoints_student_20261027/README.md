## 本轮修正与复现

20项复核JPEG和128训练张量均可从13条原片逐字节复现，未发现统一缩放或样本错配。
教师选错手、猜遮挡点仍是质量问题，几何一致不保证定位正确。

先跑一轮后，在**训练集**发现8个教师ROI的99个点投影到原画外，却被视为有效监督。
加入`teacher_source_exterior_v1`几何掩码后复跑，所有划分合计屏蔽312个画外教师点；
保留原标签数值和人工标注，没有把画外/未检出自动转成无手。
新教师导出默认写此掩码，并在复核页默认隐藏这些无效建议点；旧数据复现需显式加`--mask-outside-source`。

最终训练上限60轮、patience12、BN momentum0.9、固定seed20261026。96最佳第45轮，128最佳第39轮。
初轮未加几何掩码的模型、失败的并行评测日志均保留；内存不足后将BLAS线程限制为1并串行完成评测。
