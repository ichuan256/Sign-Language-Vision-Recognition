# 学生关键点：教师试跑与数据边界

状态：教师导出、固定来源划分、浮点训练和独立评测入口已实际跑通；
**尚无人工定位精度结论，新学生没有量化或上板。** 当前可运行 PL 网络仍是
[0.49秒基线](../keypoints_pl_20261026/stream_wide.md)。

“教师”指现成的 MediaPipe Holistic 0.10.21 软件模型：它自动估计双手21点，给学生提供伪标签。
不是视频里的老师；教师输出也会出错，不能替代人工标注。

本轮抽样没有清晰度门禁，低分辨率来源占比较高。旧200项人工队列中164项为352×288素材，
且仅100个不同源帧，因此暂不用于正式定位标注。新队列已按清晰度、来源配额和时间去重重建，
见[20帧复核说明](清晰复核说明.md)与[结构化记录](clear_review.json)。
这些局限同样约束本轮学生结果，不能把模型试跑成功当成数据质量验收通过。

新候选来自固定来源划分下的40条1080p视频：586帧、614个有手教师ROI、586个未判定区域。
最终20帧来自13条视频、4个来源组，每组5帧；12个有手候选、8个未知区域，未创建任何人工标签。
这一批只校准人工标注流程，偏向清晰教程，不能作为通用精度或跨人物结论；新数据尚未用于重训。
板端本地视频吞吐已测得约24次写入/秒，见[raw视频实测](../keypoints_pl_20261026/raw_video.md)；
它不包含关键点推理，HDMI目视仍未确认。

96/128两个学生均已完成浮点试训，使用固定来源划分；最佳轮次只按验证集选取。
96版在留出来源上的教师点平均归一化误差为0.118，平均手型基线为0.201；
PCK@0.05教师一致性约19.9%，128版约17.6%，均不等同于人工精度，尚不足以进入量化/部署。
没有人工确认的负样本，presence损失已禁用，不能报告“无手拒识已学会”。
