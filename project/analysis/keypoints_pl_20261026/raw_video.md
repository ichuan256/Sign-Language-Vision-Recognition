# 板内720p raw视频吞吐（2026-10-26）

实测120秒：**2880次帧缓冲写入，约24次/秒，未错过调度时隙**。
单帧复制P50为5.29ms、P95为5.55ms。数据见[raw_video.json](raw_video.json)。

| 项目 | 实际范围 |
|---|---|
| 输入 | 1280×720 RGB888，24帧/1秒循环，66,355,200字节 |
| 运行 | raw包事先拷到板端，预触页后从板内缓存读，逐帧无需PC传图或JPEG编解码 |
| 显示写入 | 使用既有HDMI owner的保留帧缓冲，单缓冲原位写入 |
| 固件 | bit/hwh SHA通过，未重载bitstream，未改启动项 |
| 20次/秒写入门禁 | 通过，24个不同源帧循环 |
| 屏幕目视 | 用户暂时无法查看，本轮未确认 |
| 关键点推理 | 未运行，不代表关键点达到24Hz |

数据证明短raw循环的**写入吞吐**足够，不证明VSync同步、无撕裂、物理屏幕帧率或显示延迟。
没有测长视频持续SD读取/解码、网络物理断开、与检测/关键点并发的DDR竞争。
测试已正常结束，HDMI保留最后一帧，owner保留；不能把结束画面误当测试仍在运行。

下一步是目视复验与帧边界缓冲交换，随后测实际检测器、小网络和叠加的并发端到端帧龄。
