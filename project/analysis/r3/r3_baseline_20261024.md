- 词表：清单中 ≥4 条片段的类别，共 14 类 / 59 条（分层 75/25：训练 45 / 测试 14）

## 结果

| 模型 | 测试 top-1 | 训练 top-1 | 备注 |
|---|---|---|---|
| 浮点小 CNN（4×Conv+BN+GAP+Dense） | 35.7% | 93.3% | 8s/200 轮 |
| 量化 W4/A6（QKeras QConv2D/QDense + quantized_relu(6,2)） | **42.9%** | 71.1% | 12s/200 轮 |

- 量化模型测试答对 6/14，浮点模型答对 5/14，仅差一个样本；可确认量化网络可训练，尚不能证明量化普遍无损。旧实验名虽称 w4a4，实际显式激活已放宽为 6bit，输入、BN 与累加器也并非全 4bit。
- 参照：上位机视觉嵌入 DTW LOO 28.7%、M1 关键点 DTW LOO 32.1%（不同口径，仅作量级参考）。

## 踩坑记录（复跑必读）

1. **QKeras 0.9 + TF 2.21（Keras 3）不兼容**：需脚本顶部
   `os.environ.setdefault("TF_USE_LEGACY_KERAS", "1")`（走 tf-keras/Keras 2），
   否则 `K.cast_to_floatx` 报「numpy() is only available when eager execution is enabled」。
2. **logits 配错 loss 直接不学习**：末层无 softmax 时 loss 必须
   `SparseCategoricalCrossentropy(from_logits=True)`（错配时准确率=随机水平）。
3. `quantized_relu(4)` 整数位为 0，激活值超 1 即饱和——改 `quantized_relu(6,2)`。
4. QKeras 依赖 `pyparsing` 但装的是 `pyparser` 笔误包，需手动补 `pip install pyparsing`。
