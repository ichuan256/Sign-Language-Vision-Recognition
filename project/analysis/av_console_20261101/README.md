## USB切换失败修复

用户报告USB启动失败。`project/_tmp/demo_control/20261101_063725/events.jsonl`记录两次三栏→camera失败，均为WinError 10054；对应时间没有新USB worker，旧OV worker报告流结束。原因是先停止板端采集后，PC OV worker自行退出并关闭控制口；`stop_worker()`在poll与HTTP停止请求之间撞上退出窗口，将连接关闭误报为新模式启动失败。

修复：HTTP停止接口发生OSError时继续等待原进程真正退出，确认退出才允许切换；若进程未退出则报安全停止超时，保留进程且不强杀。切换失败事件增加preflight/stop_previous/start阶段。两项回归用例覆盖“断连且进程退出”和“断连但进程仍运行”，合计22项检查通过。

实测记录：三栏`exercise_1793486754249511900/`→USB0 `exercise_1793486795900668400/`成功，USB教师177帧、HDMI51帧，error=null。控制日志目录`project/_tmp/demo_control/20261101_064351/`。只更新电脑控制软件，没有更换固件、重启或改板端运行文件；原软件包中的PC_sources代表打包时快照，后续PC界面与停止逻辑修改以工作区代码及本记录为准。本轮结束保持USB0运行。
