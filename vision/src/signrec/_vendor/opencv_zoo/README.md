# Vendored OpenCV Zoo person detector wrapper

`mp_persondet.py` is vendored unchanged from OpenCV Zoo commit `47534e27c9851bb1128ccc0102f1145e27f23f98`. The upstream model card documents the person detector, its 224×224 letterboxed input, body landmarks, and Apache-2.0 license:

- https://github.com/opencv/opencv_zoo/tree/47534e27c9851bb1128ccc0102f1145e27f23f98/models/person_detection_mediapipe
- https://github.com/opencv/opencv_zoo/blob/47534e27c9851bb1128ccc0102f1145e27f23f98/LICENSE

The corresponding ONNX weights and checksum are documented in `vision/models/person_detection_mediapipe/README.md`.
