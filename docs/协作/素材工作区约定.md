## 常用命令

```powershell
# 只读检查BV原片和ffmpeg位置，不解码、不导出。
C:\Python314\python.exe -B -X utf8 vision/tools/clipping/export_fullframe_dataset.py --preflight

# 只读检查NL第8课，避免与BV的p08混淆。
C:\Python314\python.exe -B -X utf8 vision/tools/clipping/detect_boundaries_20261022.py --lesson 8 --preflight

# 导出新版本清单：输出文件必须尚不存在；不扫描archive、inbox或缓存。
C:\Python314\python.exe -B -X utf8 vision/scripts/build_fullframe_manifest_20261024.py --source-manifest vision/data/manifests/manifest_fullframe_20261024.csv --audit vision/analysis/dataset/label_source_audit_20261025.json --output vision/data/manifests/<新文件名>.csv --allow-missing

# 打开LosslessCut：需要交互时由使用者启动。
.\vision\tools\portable\launch-losslesscut.cmd "<已找回且SHA核验的原片路径>"
```

剪裁入口支持`--repo-root`、`--source-root`、`--ffmpeg`覆盖；当前优先解析`vision/video/raw/<来源族>`，
同时保留旧布局回退并拒绝歧义。P10审定表重生成器也必须显式指定新的`--output`，不会覆盖旧表。
