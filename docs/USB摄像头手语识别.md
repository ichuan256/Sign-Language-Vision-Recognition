# USB摄像头：教师关键点后接手语识别

2026-10-29用户新增任务：先做少量演示词，再逐步扩展。在现有USB教师pipeline后接时序识别模块，不训练或修改教师关键点网络，也不修改PS/PL固件。

## 当前实现

USB实际画面 → 原MediaPipe Holistic关键点 → sign_xy_v1时序特征 → DTW少样本动作模板 → 词语候选、稳定结果或“未确定”。全部在电脑执行。
同一帧关键点同时供骨架绘制和词义识别使用，不再运行第二个教师实例。后台匹配最近1.2/2.2/3.4秒窗口，每约0.6秒提交一次，最多保留一个待处理任务，避免排队阻塞采集。
连续两次匹配稳定后才显示词语；手部消失或结果超过2.5秒后不继续显示旧词。距离和相对间隔是匹配分数，不是置信概率。阈值尚未用独立摄像头正负样本校准，词表外动作仍可能被误认。

| 原始标签 | 可用教学模板 |
|---|---:|
| 谢谢 | 4 |
| 再见 | 2 |
| 没关系 | 3 |
| 可以。 | 4 |
| 早上 | 4 |

来自当前551条活动清单的18条候选，按来源审计SHA逐一校验。1条“可以。”因教师身体/手部检测不足未进入模型，最终17条。
不合并原始标签，不将“早上”自动改成“早上好”，不自动加入85条待审素材；无需新增人工坐标标注。
模型是时序模板分类头，并非新训练的神经网络；教师结构、权重和检测设置保留，配置记录了MediaPipe版本及安装包TFLite SHA。

## 如何测试

双击`project/scripts/start_usb_sign.bat`，浏览器打开 **http://127.0.0.1:18785**。
该入口不要求板卡在线，直接使用USB摄像头0，在电脑显示骨架和手语候选；可用以下命令选择其他摄像头：

```powershell
F:/PLD/.venv-vision/Scripts/python.exe -X utf8 project/scripts/start_usb_sign.py --camera 0
```

请让上半身、肩部和双手完整入画，按教学示范完整做一个动作，再停顿后做下一个。网页“停止摄像头”释放设备，关闭网页本身不会停止后台采集。默认有界24小时，本次现场验证可使用较短`--seconds`。
USB预览用18785控制页、18784画面端口。不要同时打开第二个进程占用同一摄像头。

统一控制台的USB启动路径也已接入`usb_sign_current.json`指向的分类头，在原有HDMI链路中叠加词语。已有长驻控制服务需要正常重启后才加载新源码；本次不在线加载FPGA或改启动项。

## 实际效果与证据

按来源课次整组留出、排除同组模板，真实标签在图库中仍有其他来源示范的只有11条；候选Top-1命中3条，即3/11。这是有限教学来源的开发检查，不是跨人物或USB摄像头准确率。
因此当前版本是可运行的实验识别模块，尚未达到稳定演示的精度验收。拒识阈值、静止/非词表误触发和摄像头域迁移仍需独立测试；不能把教学模板自身回放命中当作识别准确率。
