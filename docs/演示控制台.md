# 演示控制台

当前入口为 **http://127.0.0.1:18790**。双击 `project/scripts/start_demo_control.bat` 启动服务，再打开网页。无需每次输入板卡 sudo 密码。刷新已打开的旧页面，可看到两个新按钮。

| 按钮 | 输入与计算 | HDMI显示 |
|---|---|---|
| 视听HDMI三栏 | 板端OV1、LINE IN采集，电脑原Holistic与ASR处理 | 左原始取景、中对应帧教师叠加、右语音字幕及手语视频 |
| 电脑USB摄像头识别叠加 | 电脑USB摄像头，电脑原Holistic处理；保留已有五词实验头 | 实时画面与身体、双手关键点叠加 |
| SD高动态教学视频实时处理 | 从板卡SD读取原始视频帧，电脑原Holistic实时处理 | 视频与对应帧教师关键点叠加 |
| 停止采集与识别 | 正常停止当前任务 | 保留最后一帧 |

三个模式均适配当前AV＋HPD输入固件，切换不更换位流、不重新初始化HDMI、不重启板卡。USB与SD模式已获用户实屏确认。旧PL lite、板端独立、旧OV抓图和双目选项不再显示；历史代码不作为当前控制入口。

USB默认编号0，可选1～3；打开失败会报错，不会回退到文件。五词实验头为“谢谢、再见、没关系、可以、早上”，候选分数不是准确率或概率，不能把关键点显示验收当成词义准确率验收。

SD按钮复用前版板内素材 `/home/xilinx/independent_video_20261028/frames.rgb` 与 `video.json`：三段“没关系／服务／可以”，共63帧、960×540、10fps，约6.3秒循环。启动核对原始视频SHA；每帧来自SD，骨架在运行时计算。输入按原节拍播放，处理繁忙时取最新帧；素材名不是识别结果，不读取预生成骨架，也不启动旧lite PL推理。

开机只后台启动控制服务，演示由按钮手动开始。切换会暂停语音、等待当前任务安全退出，再启动所选模式；选择三栏后恢复语音。请保持电脑登录联网、板卡和屏幕通电，HDMI接J11。关闭网页不会停止任务。

当前三个模式的教师计算都在电脑上，未实现板卡脱离电脑的完整识别，也未新增PL教师推理。用户已停止完全离线部署；不训练、不换模型。

日志在 `project/_tmp/demo_control/`；板端当前会话在 `/var/lib/sign-av/captures/` 或 `/var/lib/sign-av/displays/`。页面预览来自板端输出回读；实屏验收与软件计数分开保存。证据见[控制台适配记录](../project/analysis/av_console_20261101/README.md)，最新部署见[当前状态](当前状态.md)。
