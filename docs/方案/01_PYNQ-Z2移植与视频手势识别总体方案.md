# PYNQ-Z2 系统总体方案

更新：2026-10-28。当前视觉主线为 **保留 PS 教师网络，PL 局部加速关键点计算**。
详细实现和验收只在 [教师网络局部加速方案](04_老师模型PS_PL局部迁移.md) 维护；轻量学生训练路线已停止。

## 1. 范围与现状

| 子系统 | 范围与证据 |
|---|---|
| 视频关键点 | 当前板端手部老师为 full palm + full landmark；保留结构、权重、输入和全部输出，局部计算迁到 PL，其余留在 PS |
| 身体关键点 | 原需求保留；本轮手部子图迁移不代表完整 Holistic 或身体网络已部署 |
| 输入 | 先使用板内视频/原始帧回放；实际摄像头型号、采集状态与约束以对应硬件记录核对，不用文件回放冒充摄像头验收 |
| HDMI 与音频 | M0 移植已完成，见 [移植验收](../../project/M0_移植清单.md)；每个新增固件需复验其保留功能 |
| 旧传感器/KWS | 系统不使用传感器手套识别；历史 W6 固件仍含闲置实例，是否剥离由新工程资源预算决定 |
| 词语分类 | M1/DTW 与 R3 分类器为历史独立任务，本轮不推进，也不是关键点局部加速的前置条件 |

## 3. 目录与契约

- `project/board/teacher_hands/`：PS full 老师与运行库；当前操作入口见其 README。
- `project/algo/keypoints/`、`project/board/keypoints/`：旧整数整网实现，作为接口与构建经验参考；不能直接替代 full 老师浮点子图。
- `project/fpga/`：Vivado 2024.1 工程及冻结 RTL；新增固件在隔离目录构建。
- `vision/src/vision/`：帧源、PC 关键点与旧词语管线；`vision/data/` 存放清单/模型；本地媒体不入库。
- `ASR/`：音频上位机及常驻服务。板端音频、按键和 HDMI 的历史部署说明见 `AGENTS.md`。

旧词语链使用的 392 维 `sign_xy_v1`、掩码及来源分组约定继续有效，但不介入本轮老师图的迁移。
当前手部老师输出是原版四个张量，不复用旧 64 项 PL 协议或学生 65 项协议。

## 4. 执行顺序

1. 核对板端模型、运行库、bit/hwh 与当前进程，形成可复现的 PS 基线。
2. 记录真实视频下的阶段与算子耗时，选定一个连续子图，先核算传输与计算净收益。
3. 建立原图 delegate 接入与边界张量对照，再验证浮点 PL 核；不重新训练或自行量化。
4. 通过 C/RTL、资源和整板时序后成对冷部署；同条件验收数值、有效结果率、端到端时延与 HDMI。
5. 首段有净收益后再讨论扩展；相机、身体网络及词语分类分别验收，不扩大首轮范围。

每阶段产物、进入下一阶段的条件与停止条件详见 04 方案。此处不重复维护 FPS、学生训练状态或预测速度。

## 5. 硬件与部署约束

- 目标器件 Zynq-7020 `xc7z020clg400-1`，Vivado/Vitis 2024.1；Windows 构建经 cmd 批处理，串行执行。
- 不修改冻结 `project/fpga/rtl/` 做新开发。新候选核/工程使用独立名称、寄存器映射和 release manifest。
- bit/hwh 成对核验，备份后冷启动加载一次，接管用 `download=False`；运行中禁止二次下载。
- 保留 HDMI 时钟、复位、SOF/TUSER 契约；复验颜色、动态画面、帧号与帧龄。
- 板上已加载状态、资源余量和实际内存带宽必须现场测量，历史报告只作候选对照。

## 6. 当前验收边界

已完成的是历史 HDMI/音频移植、旧 lite PL 数值/时延试验及 PS full 老师运行记录。
新老师局部 PL 加速尚未实施，不能宣称已达 20Hz，也不能用不同网络、不同输入或不同检测频率计算加速比。
实时目标须根据同条件热点占比和首段实测结果重新评估；网络精度基准保持为冻结老师的实际输出。
