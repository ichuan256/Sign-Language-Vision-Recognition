# 路线 3 设计：PL 加速高动态手势识别（PYNQ-Z2 板端真·离线）

> 2026-10-24 · Tomcat。对应「板端离线三路线」中的路线 3。
> 目标：不依赖电脑/云端，相机进板子，PL 里跑神经网络推理，HDMI 出结果。

## 0. 工具链选型结论（今天逐项查证）

| 候选 | 结论 | 依据 |
|---|---|---|
| Vitis AI | **排除** | 不支持 Zynq-7000（xc7z020），只支持 UltraScale+/Kria |
| FINN（BNN/QNN） | 备选 | 2024.2 起 Pynq-Z1/Z2 官方退役，但构建流程未变、xc7z020 仍支持，改 `finn.util.basic` 的 `retired_pynq_boards` 可重新启用；**但 FINN 要 Linux + Docker + Linux 版 Xilinx 工具**，本机只有 Windows 版 Vivado 2024.1，引入需 WSL2 + 另装约 40GB Linux 工具链 |
| **hls4ml** | **主线** | 纯 Python（Windows 直接跑），PyTorch/QKeras 模型转 HLS C++，本机已装 **Vitis HLS 2024.1**（`F:\APP\Xilinx\Vitis_HLS\2024.1`）综合出 IP；PYNQ 社区有 Z2 落地先例 |

可行性旁证：2026 年已有论文在 PYNQ-Z2 上实现实时手势识别（轻量 depthwise
CNN + PS 采集 + PL 推理 + web 可视化）——路线 3 有已被证明的形态。

## 1. 目标指标（初定）

- 板端离线推理帧率 ≥ 10 FPS（演示可用；冲击 30）
- 词表 5~10 个高动态动作（同方案 §5 D4）
- 分组留出准确率不劣于 PC 侧基线 5 个百分点
- 整板功耗无散热器约束（Z2 无风扇，PL 利用率目标留余量）

## 2. 系统架构

```
OV5640 双目/HDMI-in（M2/M3 输入线）
   │  PL：采集 → 缩放到 64×64 灰度 → 帧缓存（8 帧均匀抽样窗口）
   ▼
PL：gesture_cls IP（hls4ml 量化小 CNN，AXI4-Stream 进出）
   │  结果（类别 + 置信度）经 AXI-Lite/中断交 PS
   ▼
PS：结果事件 → 现有结果下发通路 → HDMI 原位字幕（复用 W6 显示）
```

与方案 §4 的契约一致：识别输入抽象不变，PL 推理只是「分类器」那一档的
第三种实现（DTW 基线 / 轻量时序网络 / PL 量化网络）。

## 3. 网络草案（给 hls4ml 的输入）

- 输入张量：8 帧 × 64×64 灰度（与上位机 8 帧均匀抽样口径一致，方便 PC/PL 对照）
- 拓扑：每帧过 depthwise-separable 小 CNN（3~4 个 DS 卷积块）→ 帧嵌入 32 维
  → 时序平均池化 + 小 MLP → N 类（避开 GRU/RNN——hls4ml 对时序层支持弱）
- 量化：QKeras w4a4 起步，不够再降 w2a2；首层可 8bit
- 资源预算（Z7020 总量 53,200 LUT / 220 DSP / 140 BRAM36）：
  目标 IP 占用 < 40% LUT、< 60% DSP、< 50% BRAM；
  **W6 合一固件实测占用**（`pynq-vision/fpga/project/glove/w6_hdmi_utilization.rpt`，2026-10 构建）：
  LUT 27.7% / BRAM 31.4% / DSP 43.2%（DSP 大头是旧 HLS KWS）——
  剩余空间 LUT 72% / BRAM 69% / DSP 57%，**不剥 KWS 也装得下本设计的目标 IP**；
  若 R3.3 实测超标，再按方案 D3 剥离旧 HLS KWS（释放约 43% DSP）

## 4. 数据管线

现有 636 条全画幅精剪片段（`剪辑记录/manifest_fullframe_20261024.csv`）
→ 8 帧均匀抽样 + 缩 64×64 灰度 → 训练/验证张量集；
评测沿用 M1 的分组留出口径，与上位机两条线（视觉嵌入 DTW 28.7% LOO、
关键点 DTW 32.1% LOO）同表对照。

## 6. 风险与对策

1. hls4ml 不支持时序层 → 拓扑已规避（帧级 CNN + 池化）；
2. 资源不够 → 先扣 W6 utilization，必要时剥旧 KWS（方案 D3）；
3. Windows 路径 260 上限 → HLS/Vivado 工程一律短路径（如 `F:\r3\`）；
4. FINN 转备选的条件：hls4ml 综合结果不达标或需要 FINN 的 MVAU 极限吞吐时，
   再上 WSL2 + Linux 工具链；
5. 量化掉点 → w4a4 → w6a6 逐步放宽，首末层保持 8bit。
