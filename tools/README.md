# 辅助工具

| 位置 | 用途 |
|---|---|
| [clipping/](clipping/README.md) | 原 `剪裁方法/`：历史剪裁/核验脚本、策略表、审定边界 |
| [portable/](portable/README.md) | 原 `工具/`：便携外部工具启动入口 |

剪裁工具默认新产物放 `data/exports/`，检查图放 `_tmp/`，不再生成根目录素材文件夹。
历史剪裁脚本的 FFmpeg、原片路径需按本机实际配置核对，本轮没有重新导出视频。
日常识别、训练和审计脚本继续见 [scripts/README.md](../scripts/README.md)。
