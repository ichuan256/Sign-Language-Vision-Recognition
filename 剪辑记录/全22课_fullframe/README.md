## 复跑

剪裁方法放在项目根目录的 `剪裁方法/`，不在本数据集目录。在项目根目录执行：

```powershell
python .\剪裁方法\export_fullframe_dataset.py
```

```powershell
python .\剪裁方法\export_fullframe_dataset.py --skip-encode
```

脚本优先读取本目录内的三份来源文件，不依赖 `训练视频/` 中的清单副本；旧版 `material/` 不会被覆盖。
